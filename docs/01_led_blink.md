# Chapter 1 - LED Blink

## Overview

The goal of this step is to configure a GPIO pin manually and toggle an LED every second.

The project is based on code generated by **STM32CubeMX**, with manual modifications added in `main.c`.

---

## STM32CubeMX configuration

STM32CubeMX was used to generate the base project structure, including:

- System clock configuration
- HAL initialization
- Startup code
- Basic peripheral setup

This allows focusing only on application-level development.

---

## Manual implementation

The GPIO configuration and LED control were implemented manually using direct register access inside:

[`src/main.c`](../src/main.c)

The implementation includes:

- GPIOB clock enable
- PB0 configuration as output
- Output mode setup (push-pull)
- Pull-up / pull-down disabled
- LED toggle logic inside the main loop
